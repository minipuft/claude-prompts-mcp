## Gap

The server names an executor it ships, and the naming rule makes every executor it does not
ship unreachable. The one property the shipped agent had that the brief lacks — a tool list with
no `mcp__` entries — is a Claude-Code-only posture; the resume token never enters the brief, and
the server already records a skipped delegation, so the guarantee was already conventional for
every other client.

### Tier 2 — live-path hardening (the delegated brief renders; the earlier "never renders" finding was a null result without a positive control)

DEV-T1-3 recorded that no live path rendered a delegated brief. That was wrong, and wrong in the
way `dev-workflow.md` names: an absence recorded without first showing the probe can observe a
presence. The probes that showed nothing (`>>readme_improver ==> …`, an IR run of framework-injected
nodes) stalled at Progress 1/2 because a **framework phase-guard gate on step 1** intercepts the
resume with a gate review _before_ the chain reaches the delegated step — the gate doing its job.
