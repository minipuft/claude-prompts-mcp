- `--metrics` lengthens every catalog `--check`; measured cruise today is ~473 modules, so the cost is seconds, not minutes. Re-measure in 1.4's handoff.
- `validate:readme` on `origin/main` counts 51 prompts and passes; the interview-boundary branch's 52nd prompt is not on this branch.
