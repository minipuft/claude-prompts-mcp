## Growth Capture

- **Tracked compatibility projection:** a generated instruction file remains versioned when a
  client must discover it from a fresh checkout before project hooks can run. This is one
  project-level sighting, so it stays in this repository rather than becoming a global rule.
- **Meaning, policy, and observation stay separate:** descriptors own semantic meaning,
  Dependency Cruiser owns import permission, and the generated catalog joins meaning with observed
  edges. This is one project-level sighting and is captured in the architecture documentation and
  validator contract.
- **Correction routing:** the owner's correction from symlink to projection was recorded in the
  observation ledger and in ruling R1. No global skill or rule was changed because the pattern has
  not reached the three-sighting promotion threshold.
