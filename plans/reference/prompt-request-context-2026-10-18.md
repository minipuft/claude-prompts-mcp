# The pipeline's per-request state has one name, and the state docs match the tables

## Now (2026-10-18)

Done: the pipeline's per-request state is `PromptRequestContext`, the argument parser's context is `ArgumentContext`, and the unused third `ExecutionContext` is deleted. The architecture overview describes three state lifetimes and links to the one table map. Two new checks guard the result: `validate:table-map-docs` (the documented map against the table contracts, on every CI route) and `validate:type-name-homonyms` (no new exported type reuses a name). Shipped in one PR on `refactor/prompt-request-context`, merged before release PR #473 so it lands in 6.0.
Open outside this plan: 37 remaining type-name homonyms (the ratchet's baseline), and nothing checks method names inside doc code snippets.
