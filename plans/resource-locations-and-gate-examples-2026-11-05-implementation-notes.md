| R3i | 2026-11-10 | Owner: stacking several locations has no verb and no flag. | R3j | 2026-11-10 | Owner: a created resource is written to the main profile, the first location in the list, unless the user specifies otherwise, and every write answers with a small message naming where the file landed. On the message: the tool result carries one line, `saved: <absolute path>`, and no instruction asks the model to restate it. The owner raised the token cost of a restating standard; a one-line result the client shows is the whole mechanism.                                                                               |
| R3k | 2026-11-11 | Owner: `MCP_RESOURCES_PATH` keeps working with one meaning, an override of the active profile's `paths.resources` by that one folder, with no removal date (R3).
