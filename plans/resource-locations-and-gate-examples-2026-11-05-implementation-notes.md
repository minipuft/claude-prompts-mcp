Stacking several locations or workspaces is a separate flag, not a second `use`; the flag's shape is a planner proposal recorded in the plan. |

| 2026-11-05 | Claude Code's plugin docs: an install scope (user, project, local) selects which settings file records the plugin as enabled. The data directory is `~/.claude/plugins/data/<id>/`, one per plugin and shared by every scope, so reinstalling at another scope does not move the library. Uninstalling from the last scope deletes that directory unless `--keep-data` is passed. No page under `docs/` mentions this; row 1.6 carries it. |
| 2026-11-10 | How configuration is set today: the config file lives inside the workspace (`<workspace>/config.jsonc`), the workspace is named by `MCP_WORKSPACE` or `--workspace`, and `cpm config set <key> <value> -w <workspace>` writes it. `system_control config` serves reads only and refuses writes by design. A plugin install's workspace is `~/.claude/plugins/data/<id>/`, which held no config file on the owner's machine.                |
