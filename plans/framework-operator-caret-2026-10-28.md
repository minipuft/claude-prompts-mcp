# `^` is the framework operator; `@` is a deprecated alias

## Now (2026-10-28, evening)

Goal: every surface spells the framework operator `^`; `@` keeps working with a note.
Slice: rows 1.1–1.4 ✓ on `fix/chain-step-gates`; 2.1 take 5 recorded and shipped to the README, awaiting the owner's look.
Next decision: owner approves the cut; gemini-prompts gets its two-line follow-up row; the PR ruling for the branch.
Constraint: `publish: none`; the hold stands.

## Why

`@` is the mention and file sigil in Claude Code, Codex and Cursor, so `@ReACT` reads as a file reference in every harness that hosts this server. The server already parses `^` (`parsers/README.md`: Framework `^`, pattern `[@^]`), and the tool description the client sees says `^Framework >>prompt` with `@` deprecated. Measured 2026-10-28: the rest of the surface still writes `@` — the hook renders `@{framework}` in its output (`hooks/prompt-suggest.py:457`), `docs/reference/mcp-tools.md` (7 sites), `README.md` (6), five other docs, the operator registry and guide strings in `server/src` (~15 strings), 18 test files; bundled resources write none. The hero take's trace pane shows `@ReACT` because the hook wrote it.

## Rulings

| Id  | Ruling                                                                                                                                                                                                                                       |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | The operator is `^` (single). It is already parsed and advertised; it collides with no harness sigil; `>>` is doubled because a single `>` is a shell redirect, and `^` has no such twin. `^^` would add a second spelling for no gain.      |
| R2  | `@` stays accepted. A command using it gets one diagnostic line in the reply naming `^` as the spelling (advisory, never a refusal), the same channel other deprecations use; removal is a later major.                                      |
| R3  | The operator registry (`server/tooling/contracts/registries/operators.json`) is the SSOT for the symbol and its alias; generated contracts and metadata follow from `generate:contracts`, never by hand. Docs quote the registry's spelling. |
| R4  | The hook writes `^{framework}` wherever it echoes the operator (its routing line, the trace), and detects both spellings. Its tests assert both the detection of `@` and the rendering of `^`.                                               |
| R5  | Downstream prompt repos (gemini-prompts, opencode-prompts, codex-prompts) are inventoried, not edited, in this slice; each hit becomes a follow-up row in that repo's plan.                                                                  |
