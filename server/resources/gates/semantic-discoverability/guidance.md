## Semantic Discoverability

Improve how readers and search systems identify the product without changing its claims.

### Guidance criteria

- State the product category and primary problem in the opening description.
- Use terms a technical reader may search for, including MCP, AI workflow, prompt workflow, validation, versioning, and supported client names only where accurate.
- Keep one canonical term for each concept; define project terms on first use.
- Prefer descriptive headings that match reader tasks over internal subsystem names.
- Do not repeat keywords unnaturally, invent market claims, or broaden capabilities for search visibility.

Report proposed terminology changes separately from factual corrections.
